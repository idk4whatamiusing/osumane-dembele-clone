# Ousmane Dembélé — Né Pour Briller

A personal tribute recreation of the official Ousmane Dembélé Ballon d’Or website.

- **Original site:** https://www.ousmaneballondor.fr
- **Live version:** https://osumane-dembele-clone.dsjzcjmsh6.workers.dev

## What this is

An interactive journey through Ousmane Dembélé’s career, following the original site’s cinematic opening, introduction, five club chapters, jersey moments, photo galleries, match footage, career statistics, and trophy finale.

It is designed to work on both desktop and mobile, with smooth transitions, video, sound, and a hold-to-listen **HOLD ME** control in the footer.
